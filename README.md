### 🔬 What I work on

- 🤖 **Deep reinforcement learning**: multi-agent systems, actor-critic, robots learning to walk, game agents
- 🎵 **Generative audio**: music synthesis with diffusion models, GANs and liquid networks
- 🧠 **Paper re-implementations**: Liquid Time-constant Networks, Kolmogorov-Arnold Networks, TabPFN, Iterative Machine Teaching
- 🛠️ **C++ & simulation**: LibTorch, physics engines (Bullet, Jolt), OpenGL / Vulkan
